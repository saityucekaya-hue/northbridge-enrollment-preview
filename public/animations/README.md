# College life animations

These three dotLottie files are used in the sample offer acceptance transition. Each was published as a free animation under the [Lottie Simple License](https://lottiefiles.com/page/license) and is bundled locally so the preview does not depend on an animation CDN at runtime.

| File | Creator and source |
| --- | --- |
| `learning.lottie` | [Student Studying, Kiirya Arnold](https://lottiefiles.com/free-animation/student-studying-N6b6Aybob2) |
| `sporting.lottie` | [Marathon, Maksim Turkov](https://lottiefiles.com/free-animation/marathon-6CNBbR24va) |
| `debating.lottie` | [Conversation, Keeks P.](https://lottiefiles.com/free-animation/conversation-f1Oo9sBdYF) |

The other campus activities are listed as future possibilities; they are not represented by unrelated character animations.
